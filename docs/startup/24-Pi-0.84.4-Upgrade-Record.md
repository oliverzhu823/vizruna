## 1. 升级边界

本次只升级 Pi 内核及其兼容层，不进行 Runtime 拆分、RPC 重构、CLI 开发或用户数据迁移。
`@earendil-works/pi-ai` 与 `@earendil-works/pi-coding-agent` 均精确锁定为 `0.84.4`，不使用
范围版本。

## 2. 模型与思考度策略

Pi 0.84.4 的模型和思考度修改默认只作用于当前会话。Vizruna 明确采用以下规则：

- 聊天界面中的模型和思考度切换使用 `persist: false`，不改写 Pi 全局默认值。
- Vizruna 继续通过 `lastModel` 与 `lastThinking` 将上一次有效选择传给新会话。
- 只有设置页面可以修改 Pi 全局默认模型和默认思考度。
- Agent 配置与普通会话不会因为一次临时模型切换而互相污染。

## 4. 发布前人工门禁

在标记为公开 Alpha 候选前，仍需在真实界面完成：

1. OpenAI Codex OAuth 登录、重新登录、退出与再次登录。
2. GLM API 模型发起一轮真实对话。
3. Codex 模型发起一轮真实对话。

5. 使用 Agent 配置运行一次，确认固定模型、System Prompt、Skills 与工具实际加载。

任一项出现 P0 回归时，回退 Pi 依赖与锁文件到 `0.84.1`；本次没有绑定数据库迁移，因此
回退不需要修改用户数据。
